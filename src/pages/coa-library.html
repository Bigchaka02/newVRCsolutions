How to read a certificate

Four things on the report should match four things on your vial. If any one of them does not, tell us.

What to check
Lot numberThe code on the report matches the code printed on your vial label, character for character.
Compound identityMass spectrometry confirms the molecular weight expected for that compound.
PurityHPLC percentage at or above our 99% cutoff for peptides.
Test dateDated before the batch entered inventory, not after.
